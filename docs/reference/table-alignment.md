# 表格对齐规范（字段 → 对齐方式）

> **唯一依据（Single Source of Truth）**：本站所有表格的列对齐**只以本文档为准**。
> 新增/修改任何表格字段时，先在本文档登记字段与对齐方式，再按登记值实现，**不得各自为政**。
> 生效日期：2026-10-03（用户要求全站统一）。

---

## 一、总则（三类字段 + 两类可居中例外）

| 字段类别 | 对齐 | 说明 | 示例字段 |
|---|---|---|---|
| **文本 / 标签类** | **左对齐** | 代码、名称、简称、分类、来源、市场、币种等文字与标签 | 基金代码、基金名称、股票代码、证券简称、分类名称、ETF代码、跟踪指数名称、币种、来源、目标市场 |
| **数值类** | **右对齐** | 一切可比的数字量（含带单位的数字） | 净值、涨跌幅、股息率、规模、成交额、份额占比、成分个数、管理费率、年度分红次数、月均分红 |
| **日期类** | **左 / 右（见下）** | 分两个子类，**同子类全站统一** | 元数据日期 → 左；时效/分红日期 → 右 |
| ⭐ 短徽章类（例外） | **可居中** | 仅限状态徽章，非可比数据列 | 风险等级、多空标签等 |

### 日期类字段的二级规则

| 日期子类 | 判定标准 | 对齐 | 本站字段 |
|---|---|---|---|
| **元数据日期** | 静态说明性、不用于「新旧/先后」比较 | **左对齐** | 成立日期、上市日期、发布日期、更新日期（数据日期） |
| **时效/分红日期** | 用于比较「最新/最近」（新旧、先后） | **右对齐** | 最近分红日期、派息日 |

> ⚠️ 「同一类日期字段在全站保持统一选择」：凡「成立/上市/发布/更新日期」一律左；凡「最近分红/派息日」一律右。新表新增日期列时，先判断属于哪个子类再登记。

### 表头规则（强制）

**表头文字的对齐方式必须与该列数据的对齐方式一致**（左列左表头、右列右表头）。**禁止**表头统一居中。
唯一允许居中：短徽章列 / 图标列（如首页资产表最右的 ☆ 收藏列）。

> **排序图标位置（2026-10-03）**：**右对齐列**（`col-num` / `col-date-r` / `col-yield` / `col-pct`）的排序图标必须落在**文字的左侧**——做法 = 给该表头 `direction: rtl`（图标 vs 文字的左右留白随之对调）。原因：排序图标（`.sort-icon`，12px + 3px 间距）**即使隐藏（`visibility:hidden`）也占位**，在右对齐列里会把表头文字整体左推 ~15px → 文字右沿与数据右沿错位（用户反馈「涨跌幅」的「幅」对不齐下方数字）。改到左侧后，文字仍贴右沿、与数据右沿**严格对齐**，且图标占位保留（列宽不跳）。**左对齐列**的图标仍在文字右侧（`direction` 保持默认 `ltr`）。首页资产表同规则（`.asset-table-header span:nth-child(3)` 食息率 = `text-align:right + direction:rtl`）。

### 单元格留白规则（2026-10-03，用户反馈「文字贴单元格边界 / 相邻列黏连」；当日二次定稿：**10px inset / 相邻 ≥20px**）

**每个单元格左右各留** **10px** **内边距（inset），文字不得贴到单元格边界；相邻两列文字之间必须有** **≥20px** **可见间隙。**

| 表 | 单元格水平内边距 | 相邻列最小文字间隙 | 说明 |
|---|---|---|---|
| `.index-table`（5 张列表） | `th/td { padding: … 10px }`（`col-num`/`col-date-r`/`col-yield`/`col-pct` 同） | 20px | 右对齐列紧邻左对齐列时为 10+10=20px |
| 首页 `.asset-table`（grid） | `.asset-*-cell { padding: 0 10px }` + 行/表头外 `padding: … 4px` | 24px | 10+4(gap)+10=24px；外沿 = 4+10 = 14px |

> ⚠️ 根因：右对齐列的右沿贴其单元格右界、下一列左对齐列的左沿贴其单元格左界 → 两列文字间距只剩「列间隙」（grid gap / 相邻 padding）。**新增右对齐列时，务必确认其右侧相邻列仍有 ≥20px 文字间隙。**
> ⚠️ 定稿口径（v0.1.40）：全站单元格水平 inset 统一 **10px**，相邻列文字间隙 ≥**20px**（资产表实测 24px、列表实测 20px）。平板（`mobile.css`）`.index-table th/td` 同步 10px。

### 表格行高（2026-10-03 二次）

表格行/表头的**纵向**内边距用专用令牌 **`--pad-row-tb`**（当前 **11px**），与内容框体的 `--pad-row: 18px` 区分：
- 行高 = 单元格 `line-height`（≈19.6px）+ 2 × `--pad-row-tb` ≈ **42~45px**（由 v0.1.31 的 56~59px 缩 **≈ −25%**，用户要求「缩 ~1/4」）。
- 使用者：`.asset-table-header`、`.asset-row`、`.index-table th/td`、平板 `.index-table th/td`（`mobile.css`）。
- 手机卡片 `.index-table tr`/`.asset-row`、`.m-card` 与 `.blog-overlay-body th/td` **仍用 `--pad-row`（18px）**（卡片/非表格行）。

## 二、实现约定（代码层）

| 机制 | 位置 | 说明 |
|---|---|---|
| `.index-table th.col-num / td.col-num` | `index.html` `<style>` | 数值列**右对齐**（表头与数据同用此类名） |
| `.index-table th.col-date-r / td.col-date-r` | `index.html` `<style>` | 时效/分红日期列**右对齐** |
| `.index-table .col-yield` / `.col-pct` | `index.html` `<style>` | 股息率 / 涨跌幅：既含配色字重，也含 `text-align:right` |
| 文本/标签/元数据日期列 | 默认 | **不加类名**，走 `.index-table th/td` 默认 `text-align:left` |
| 首页资产表（grid 版） | `.asset-table-header span:nth-child(n)` + `.asset-*-cell` | 逐列显式声明左/右；表头与单元格同值 |

> 新增数值列：给该列 `<th>` 与 `<td>` 同时加 `class="col-num"`；
> 新增时效日期列：同时加 `class="col-date-r"`；文本列不加类名（默认左）。

## 四、不适用本规则的表 UI（说明，避免误改）

| UI | 原因 |
|---|---|
| 详情页 `.detail-info-row`（键值对行） | 非多列表格，属「label 左 / value 右」的键值布局，value 恒右置，与列对齐无关。⚠ 2026-10-04：**长文本行**（`.detail-info-row--desc`，如资产详情「指标详情」）在 web 端改为**上下堆叠、左对齐**（label 上 / value 下），避免长内容与标签相贴；短值行仍保持「label 左 / value 右」不变。所有行加 `gap:16px` 保证标签与数值永不相贴 |
| 食息资讯 `.df-items li`（素材卡） | 卡片流，非表格，正文/标签天然左对齐 |
| 收藏 `.fav-item` | 卡片流（左信息 + 右收益），非表格 |
| 博客正文 markdown 表格 | 暂无表格解析（`mdToHtml` 未实现表格）；栏目建设中，暂不涉及 |

> 若日后详情页键值行改为真正的多列表格，或博客接入 markdown 表格渲染，须回到本文档先登记字段对齐方式。
