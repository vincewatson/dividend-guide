# 色彩管理 · Tailwind CSS v4 色板

> **来源**：[uicolors.app/tailwind-colors](https://uicolors.app/tailwind-colors)（Tailwind CSS v4 全色板，抓取自 2026-08-22）
> **用途**：本项目（食息指南）配色管理参考文档。共 **26 个色板 × 11 阶**（50–950）。
> **使用约定**：选色先看本表；同一交付/页面锁定一个色板家族（明度即数据），不混用多色板。
